        正常模式：
        ┌─────────────┐     ┌─────────────┐
        │ Windows A   │────>│ Ubuntu MySQL│<────│ Windows B   │
        │ 回测+写入   │     │   主数据库   │     │ 回测+写入   │
        └─────────────┘     └─────────────┘     └─────────────┘

                                    ↓
                        ┌────────────┴────────────┐
                        ↓                         ↓
                Windows A 本地SQLite      Windows B 本地SQLite
                （备份副本）              （备份副本）

        故障模式（Ubuntu不可用）：
        ┌─────────────┐                 ┌─────────────┐
        │ Windows A   │────写入────>    │ 本地SQLite  │
        │ 回测        │                 │ （临时）     │
        └─────────────┘                 └─────────────┘

        恢复后：
        本地SQLite新数据 ──合并──> Ubuntu MySQL

        | 优点               | 缺点               |
        |--------------------|--------------------|
        | 故障自动切换       | 需要合并逻辑       |
        | 无需Windows装MySQL | 故障期间数据在本地 |
        | 恢复后可合并       | 实现稍复杂         |

        可行性：高，推荐
