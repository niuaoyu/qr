arrange_combine：排列组合的工具包

        排列组合的模板
    \worldquant\arrange_combine\generate_alpha_txt.py
        模板生成对应的a表达式（无设置的配置，只是生成a表达式模板）

        功能和main.py类似，只不过main配置不变，便于大量运行
        run_and_log_alphas.py建议少量模板+设置，举例3个a+10个设置组合=3*10=30个alpha
